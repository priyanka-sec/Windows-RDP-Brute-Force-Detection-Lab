This section contains visual representations of the simulated RDP attack and the investigation workflow.

The diagrams are designed to provide a clear understanding of:

- SOC investigation methodology
- Defensive improvements after mitigation

These visuals help translate raw log analysis into an easy-to-understand security narrative.

## 🎯 Why These Diagrams Matter

In real-world SOC environments, visual models help:
