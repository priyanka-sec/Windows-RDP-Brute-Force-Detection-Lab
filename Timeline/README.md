# Incident Timeline

This folder contains the authentication activity timeline reconstructed during the Windows RDP Brute Force Detection & Log Analysis investigation.

The timeline was created using Windows Security Event Logs generated during both failed and successful RDP authentication attempts.

## Timeline Activities

- RDP Environment Configuration
- Connectivity Verification
- Failed Authentication Attempts
- Successful Authentication Events
- Security Event Investigation
- PowerShell Event Hunting
- Authentication Correlation
- SOC Investigation Workflow

## Purpose

Timeline reconstruction is an important SOC investigation technique used to understand attacker behavior, authentication sequences, and suspicious activity patterns during security investigations.
