# Reports

This folder contains SOC-style investigation reports and security analysis documentation created during the Windows RDP Brute Force Detection Lab.

The reports summarize authentication activity, investigation findings, detection logic, indicators of compromise (IOCs), and mitigation recommendations identified throughout the project.

## Report Areas

- Incident Summary
- Authentication Analysis
- Event Log Investigation
- Detection Findings
- IOC Identification
- MITRE ATT&CK Mapping
- Security Recommendations

## Purpose

The purpose of these reports is to demonstrate SOC investigation documentation practices commonly used in enterprise cybersecurity environments.

This folder showcases the ability to document findings, explain attack behavior, and communicate investigation results in a professional format.
