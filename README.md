<h1>Windows-RDP-Attack-Lab</h1>



## Introduction

## Overview
This project demonstrates a Windows RDP (Remote Desktop Protocol) attack lab. 

It helps to understand how attackers attempt to access Windows systems and how to detect, mitigate, and monitor these attacks.

<br>

## Objective
- Learn how Windows Server 2022 logs successful and failed login attempts.
- Understand Event IDs (4624 and 4625) and their meaning.
- Practice monitoring and mitigation techniques for RDP attacks.
- Build skills in SOC monitoring, incident response, and cybersecurity best practices.




## Prerequisites
- VirtualBox installed on your system
- Kali Linux VM (attacker machine)
- Windows Server 2022 VM (victim machine)
- Basic understanding of RDP and Event Viewer




## Learning Outcomes
- How to identify successful (4624) and failed (4625) logins.
- How to monitor logs for RDP attacks.
- Mitigation techniques for RDP vulnerabilities.
- Hands-on experience with Event Viewer and SOC analysis.
