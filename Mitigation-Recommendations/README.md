# Mitigation Recommendations

This folder contains security hardening recommendations and defensive measures for protecting Windows systems against Remote Desktop Protocol (RDP) authentication attacks.

The recommendations were created based on observations made during the authentication monitoring and investigation process.

## Security Areas Covered

- RDP Hardening
- Account Protection
- Authentication Security
- Access Control
- Remote Access Security
- Monitoring Improvements
- Log Management Recommendations

## Recommended Security Controls

- Enable Multi-Factor Authentication (MFA)
- Restrict RDP Access
- Implement Account Lockout Policies
- Use Strong Password Policies
- Limit Public RDP Exposure
- Monitor Authentication Logs
- Apply Firewall Restrictions
- Enable Centralized Logging

## Purpose

The goal of this folder is to demonstrate defensive security thinking and showcase how SOC analysts recommend mitigation strategies after identifying suspicious authentication activity.
