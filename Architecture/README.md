# Architecture

This folder contains the architecture diagram and lab design used for the Windows RDP Brute Force Detection & Log Analysis Lab.

The environment was built in a controlled VirtualBox setup to simulate Remote Desktop Protocol (RDP) authentication activity between Kali Linux and Windows Server 2022 systems.

## Lab Components

- Kali Linux (Attacker Machine)
- Windows Server 2022 (Victim Machine)
- VirtualBox Virtualized Environment
- Host-Only Network Communication
- Windows Event Viewer for Log Analysis
- PowerShell for Event Hunting

## Purpose

The architecture was designed to simulate authentication monitoring, failed login detection, successful RDP authentication analysis, and SOC investigation workflows commonly used in enterprise environments.
