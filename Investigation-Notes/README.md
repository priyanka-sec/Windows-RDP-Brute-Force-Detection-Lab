# Investigation Notes

This folder contains SOC investigation notes and authentication analysis findings collected during the Windows RDP Brute Force Detection Lab.

The investigation focused on analyzing Windows Security Event Logs generated during failed and successful RDP authentication attempts.

## Investigation Areas

- Event ID 4625 Analysis
- Event ID 4624 Analysis
- Authentication Failure Investigation
- Successful RDP Login Analysis
- Source IP Correlation
- Logon Type Investigation
- Authentication Timeline Analysis

## Purpose

The purpose of these notes is to document the investigation methodology, findings, and authentication behavior observed during the simulated RDP attack activity.

This folder reflects the type of documentation commonly maintained by SOC analysts during authentication-related investigations.
