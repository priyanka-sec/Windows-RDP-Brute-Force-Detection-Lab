# EventID 4624 — Successful Logon Analysis
## INC-RDP-2026-001

**Analyst:** Priyanka Rane — SOC L1
**Date:** 26 May 2026

<br><br>

## What is EventID 4624?

EventID 4624 is generated by Windows Security when an account
successfully logs on. In the context of a brute force attack,
a 4624 event following multiple 4625 events from the same
source IP confirms the attacker successfully gained access.

<br><br>

## Key Fields Observed

| Field | Value | SOC Significance |
|---|---|---|
| TargetUserName | socuser | Same account that was targeted |
| IpAddress | 192.168.56.10 | Same attacker IP — confirms success |
| LogonType | 10 | RemoteInteractive — RDP session confirmed |
| LogonProcess | User32 | Standard RDP logon process |
| AuthenticationPackage | NTLM | Weak auth protocol confirmed |

<br><br>

## Logon Type Reference

| Logon Type | Description | SOC Relevance |
|---|---|---|
| 2 | Interactive — local console | Low risk |
| 3 | Network — SMB/file share | Medium risk |
| 10 | RemoteInteractive — RDP | HIGH RISK — attacker on system |
| 7 | Unlock — screen unlock | Low risk |

**Logon Type 10 = Attacker has an active RDP session on the server.**

<br><br>

## Attack Success Confirmation Query

```splunk
index=main (EventCode=4625 OR EventCode=4624)
| eval event_type=if(EventCode=4624,"SUCCESS","FAILURE")
| table _time, event_type, Account_Name
| sort _time
```

**Result:** Chain of FAILURE events ending in SUCCESS —
confirms brute force attack succeeded.

<br><br>

## SOC Analyst Conclusion

EventCode 4624 with Logon Type 10 from the same IP that
generated 142 failed login attempts confirms the attacker
successfully authenticated via RDP. This escalates the
incident from attempted breach to confirmed breach.

**Immediate Action Required: P2 — High — Containment initiated.**
