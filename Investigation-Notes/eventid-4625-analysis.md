# EventID 4625 — Failed Logon Analysis
## INC-RDP-2026-001

**Analyst:** Priyanka Rane — SOC L1

<br><br>

## What is EventID 4625?

EventID 4625 is generated by Windows Security when an account
fails to log on. It is the primary indicator of brute force,
password spraying, and credential stuffing attacks.

<br><br>

## Key Fields in EventID 4625

| Field | Value Observed | SOC Significance |
|---|---|---|
| TargetUserName | socuser | Single account targeted — password guessing |
| IpAddress | 192.168.56.10 | Single source — confirms brute force |
| LogonType | 10 | RemoteInteractive — RDP attack confirmed |
| FailureReason | Unknown username or bad password | Credential guessing confirmed |
| LogonProcess | NtLmSsp | NTLM authentication used |

## Splunk Detection Query Used

```splunk
index=main EventCode=4625
| bucket _time span=5m
| stats count by _time, host
| eval severity=if(count>50,"CRITICAL",if(count>20,"HIGH","MEDIUM"))
| sort -count
```

<br><br>

## SOC Analyst Conclusion

142 EventCode 4625 events from a single source IP targeting
a single account over 8 minutes is a confirmed brute force
attack. The pattern — rapid sequential failures with identical
target username — is inconsistent with any legitimate activity.

**Classification: True Positive — Brute Force Attack Confirmed**
